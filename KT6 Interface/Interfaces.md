

# Лекция: Интерфейсы в C#

## Что такое интерфейс?

**Интерфейс** в C# — это "контракт", который определяет набор методов, свойств или событий, но **не содержит их реализации**.
Класс или структура, реализующие интерфейс, **обязаны** реализовать все его члены.

---

## Зачем нужны интерфейсы?

1. **Разделение обязанностей** – отделение описания поведения от его реализации.
2. **Гибкость** – возможность менять реализацию без изменения кода, который использует интерфейс.
3. **Полиморфизм** – работа с разными объектами через единый интерфейс.
4. **Множественное наследование** – класс может реализовывать несколько интерфейсов (в отличие от наследования только одного класса).

---

## Примеры из жизни

* **Розетка** → стандарт (интерфейс), приборы → реализации.
* **Водительские права** → подтверждают, что человек умеет водить (но на чём именно — не важно).
* **Музыкальный инструмент** → интерфейс `IPlayable` (можно "играть"), но каждый инструмент делает это по-своему.

---

## Пример: интерфейс и несколько реализаций

```csharp
public interface IPlayable
{
    void Play();
}

public class Guitar : IPlayable
{
    public void Play() => Console.WriteLine("Играю на гитаре 🎸");
}

public class Piano : IPlayable
{
    public void Play() => Console.WriteLine("Играю на пианино 🎹");
}
```

### Использование

```csharp
class Program
{
    static void Main()
    {
        List<IPlayable> instruments = new List<IPlayable>
        {
            new Guitar(),
            new Piano()
        };

        foreach (var instrument in instruments)
        {
            instrument.Play();
        }
    }
}
```

## Пример: интерфейсы для разных "способностей"

Интерфейсы можно комбинировать.

```csharp
public interface IMovable
{
    void Move();
}

public interface IFlyable
{
    void Fly();
}

public class SuperHero : IMovable, IFlyable
{
    public void Move() => Console.WriteLine("Герой бежит!");
    public void Fly() => Console.WriteLine("Герой взлетает!");
}
```

## Итоги

* Интерфейс = контракт без реализации.
* Используется для гибкости и полиморфизма.
* Позволяет работать с разными объектами по единым правилам.
* В C# можно реализовать несколько интерфейсов одновременно.
