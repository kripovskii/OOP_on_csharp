# **Задание: Работа с обобщениями в C#**

### **Часть 1. Обобщённый класс**

1. Создай обобщённый класс `Box<T>`, который хранит **один элемент любого типа**.
2. Добавь методы:

   * `void Put(T item)` — положить элемент в коробку.
   * `T Get()` — достать элемент из коробки.
3. Создай несколько объектов класса:

   * `Box<int>` и положи число.
   * `Box<string>` и положи строку.
4. Выведи значения на экран.

**Пример вывода:**

```
Число в коробке: 42
Строка в коробке: Hello
```

---

### **Часть 2. Обобщённый метод**

1. Добавь статический метод `Swap<T>(ref T a, ref T b)` в отдельный класс `Utils`, который меняет местами два значения.
2. Проверь работу метода на:

   * Двух числах.
   * Двух строках.

**Пример вывода:**

```
Числа после Swap: 10, 5
Строки после Swap: World, Hello
```

---

### **Часть 3. Ограничения**

1. Создай обобщённый класс `Repository<T>`, который должен работать **только с классами** и у которых есть **пустой конструктор** (`where T : class, new()`).
2. В классе добавь метод `T CreateNewItem()` — создает новый объект `T`.
3. Проверь работу с любым пользовательским классом, например:

```csharp
class User
{
    public string Name { get; set; } = "NoName";
}
```

**Пример использования:**

```csharp
Repository<User> repo = new Repository<User>();
User u = repo.CreateNewItem();
Console.WriteLine(u.Name); // NoName
```

---

### **Часть 4 (дополнительно). Пара значений**

1. Создай обобщённый класс `Pair<T1, T2>` для хранения двух значений разных типов.
2. Создай объект `Pair<int, string>` и выведи оба значения.

**Пример вывода:**

```
Первое значение: 5, Второе значение: Hello
```
