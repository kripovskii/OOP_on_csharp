# Задание 1. Класс Book
Создайте класс Book, который должен содержать:
- публичное поле `Title` (название книги);

- приватное поле `_pages` (количество страниц);

- свойство `Pages` для доступа к `_pages` (значение должно быть ≥ 1);

- метод `PrintInfo()`, который выводит информацию о книге.

**Пример использования:**
```csharp
Book b = new Book();
b.Title = "Преступление и наказание";
b.Pages = 500;
b.PrintInfo();

```
**Ожидаемый результат:**
```
Книга: Преступление и наказание, страниц: 500
```

# Задание 3. Класс Rectangle

Создайте класс Rectangle, который должен содержать:

- приватные поля `_width` и `_height`;

- свойства `Width` и `Height` с проверкой (значение должно быть > 0);

- метод `Area()`, который возвращает площадь прямоугольника.

**Пример использования:**
```csharp

Rectangle r = new Rectangle();
r.Width = 5;
r.Height = 10;
Console.WriteLine($"Площадь: {r.Area()}");
```

**Ожидаемый результат:**
```
Площадь: 50
```
