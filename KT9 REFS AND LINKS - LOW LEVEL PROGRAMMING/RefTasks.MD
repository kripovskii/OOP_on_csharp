## Задание 1 (Базовое): Обмен значений

Цель: Понять разницу между передачей параметров по значению и по ссылке с помощью `ref`.

Напишите два метода `SwapWithoutRef` и `SwapWithRef`, которые меняют местами значения двух целочисленных переменных.

1. `SwapWithoutRef` принимает два параметра по значению. Продемонстрируйте, что исходные переменные в вызывающем методе не изменятся.
2. `SwapWithRef` принимает два параметра с ключевыми словами `ref`. Продемонстрируйте, что этот метод меняет значения исходных переменных.

### Ожидаемый вывод:
```bash
Исходные значения: x = 5, y = 10
Внутри SwapWithoutRef: a = 10, b = 5
После SwapWithoutRef: x = 5, y = 10

Внутри SwapWithRef: a = 10, b = 5
После SwapWithRef: x = 10, y = 5
```

## Задание 2 (Практическое): Сброс значения ссылочного типа

Цель: Научиться использовать `ref` для изменения самой ссылки (а не содержимого объекта) в ссылочном типе.

Иногда нужно не только изменить состояние объекта (например, с помощью его методов), но и полностью заменить объект на новый или присвоить ему значение `null`. Без `ref` это невозможно, так как в метод передается копия ссылки.

Создайте класс `Person`. Напишите два метода для "сброса" объекта этого класса:

1. `ResetPersonWithoutRef` - пытается установить входящий параметр в `null`.
2. `ResetPersonWithRef` - с помощью `ref` устанавливает входящий параметр в `null`.

### Ожидаемый вывод:
```bash 
Исходные данные:
Name: Алексей, Age: 30
Name: Мария, Age: 25

--- Попытка сброса БЕЗ ref ---
Внутри ResetPersonWithoutRef: person установлен в null.
person1 не null: Name: Алексей, Age: 30

--- Попытка сброса С ref ---
Внутри ResetPersonWithRef: person установлен в null.
person2 is null.

--- Изменение состояния объекта (без ref) ---
Name: Петр, Age: 30

```
