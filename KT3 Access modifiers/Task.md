# Практическое задание: Модификаторы доступа в C# - Класс Student

### Описание задачи
Создать класс `Student` для управления информацией о студентах. Реализовать методы с разными модификаторами доступа, обосновав выбор каждого модификатора.


## Задачи для выполнения

**Задача 1: Реализуйте класс `Student`**
- Используйте не менее 4 разных модификаторов доступа
- Добавьте комментарии к каждому методу с обоснованием выбора модификатора

**Задача 2: Создайте производный класс `AdvancedStudent`**
- Продемонстрируйте использование protected методов и полей
- Переопределите или добавьте новые методы

**Задача 3: Создайте класс `StudentManager` в той же сборке**
- Продемонстрируйте использование internal методов и полей

**Задача 4: Напишите тестовую программу**
- Покажите корректное использование public методов
- Продемонстрируйте, что доступ к private/protected методам невозможен извне


## Рекомендации

1. **private** - для внутренней логики, которая не должна быть доступна извне
2. **protected** - для functionality, которая может понадобиться наследникам
3. **internal** - для методов, нужных только внутри вашей библиотеки/сборки
4. **public** - для основного API, который будут использовать другие разработчики
5. **protected internal** - для методов, которые нужны и в сборке, и наследникам
