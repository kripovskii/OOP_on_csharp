
##  Пример 1. Указатель на переменную

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int number = 42;
        int* ptr = &number; // указатель на переменную

        Console.WriteLine($"Значение: {number}");
        Console.WriteLine($"Адрес: {(ulong)ptr:X}");
        Console.WriteLine($"Значение через указатель: {*ptr}");

        *ptr = 100; // изменяем значение по адресу
        Console.WriteLine($"Новое значение: {number}");
    }
}
```

**Что происходит:**

* `&number` — берём адрес переменной.
* `int* ptr` — создаём указатель на `int`.
* `*ptr` — разыменовываем указатель, получаем доступ к значению.

---

##  Пример 2. Указатель на указатель (pointer to pointer)

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int value = 10;
        int* p1 = &value;    // указатель на int
        int** p2 = &p1;      // указатель на указатель

        Console.WriteLine($"value = {value}");
        Console.WriteLine($"*p1 = {*p1}");
        Console.WriteLine($"**p2 = {**p2}");

        **p2 = 99; // изменяем значение через двойной указатель
        Console.WriteLine($"Новое значение value = {value}");
    }
}
```

**Как это работает:**

* `p1` хранит адрес переменной `value`.
* `p2` хранит адрес указателя `p1`.
* `**p2` позволяет “достучаться” до самой переменной `value`.

---

##  Пример 3. Работа с массивом через указатель

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int[] arr = { 1, 2, 3, 4, 5 };

        fixed (int* p = arr) // "фиксируем" массив в памяти
        {
            for (int i = 0; i < arr.Length; i++)
            {
                Console.WriteLine($"Элемент {i}: *(p + {i}) = {*(p + i)}");
                *(p + i) *= 2; // умножаем каждый элемент на 2
            }
        }

        Console.WriteLine("Массив после изменений:");
        Console.WriteLine(string.Join(", ", arr));
    }
}
```

**Важно:** оператор `fixed` не даёт сборщику мусора переместить массив во время работы с указателем.

##  Пример 4. Использование `stackalloc` (память на стеке)

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int* p = stackalloc int[5]; // выделяем память на стеке
        for (int i = 0; i < 5; i++)
            p[i] = i * i;

        Console.WriteLine("Данные в stackalloc:");
        for (int i = 0; i < 5; i++)
            Console.WriteLine(p[i]);
    }
}
```

**Особенность:** память автоматически освобождается при выходе из метода.

##  Пример 5. Работа с указателем на структуру

```csharp
using System;

struct Point
{
    public int X;
    public int Y;
}

class Program
{
    unsafe static void Main()
    {
        Point p = new Point { X = 5, Y = 10 };
        Point* ptr = &p;

        Console.WriteLine($"До: X = {ptr->X}, Y = {ptr->Y}");
        ptr->X = 20;
        ptr->Y = 40;
        Console.WriteLine($"После: X = {p.X}, Y = {p.Y}");
    }
}
```

**Оператор `->`** работает так же, как в C/C++ — доступ к полям структуры через указатель.

##  Пример 6. Комбинированный пример — указатель на указатель с массивом

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int a = 1, b = 2, c = 3;
        int*[] arr = { &a, &b, &c }; // массив указателей

        fixed (int** p = arr) // указатель на первый элемент массива указателей
        {
            for (int i = 0; i < arr.Length; i++)
            {
                Console.WriteLine($"Значение через **(p + {i}) = {**(p + i)}");
                **(p + i) += 10; // изменяем каждое значение
            }
        }

        Console.WriteLine($"a={a}, b={b}, c={c}");
    }
}
```

##  Вывод

| Что делает              | Пример                 | Ключевая особенность           |
| ----------------------- | ---------------------- | ------------------------------ |
| Указатель на переменную | `int* p = &x;`         | доступ к памяти напрямую       |
| Указатель на указатель  | `int** pp = &p;`       | двойное разыменование          |
| Указатель на массив     | `fixed (int* p = arr)` | фиксирует объект               |
| Память на стеке         | `stackalloc`           | очень быстрая временная память |
| Указатель на структуру  | `ptr->field`           | работа с полями напрямую       |



## 🔹 Пример 1. Обычный указатель

```csharp
int number = 42;
int* ptr = &number;
```

**Схема памяти:**

```
┌──────────────┐
│   number     │
│  (значение)  │ 42
│  (адрес)     │ 0x100
└──────────────┘

┌──────────────┐
│    ptr       │
│  (значение)  │ 0x100  ← адрес number
│  (адрес)     │ 0x200
└──────────────┘
```

>`ptr` хранит **адрес** `number`, а `*ptr` обращается к **значению по адресу** `0x100`, то есть `42`.



## 🔹 Пример 2. Указатель на указатель

```csharp
int value = 10;
int* p1 = &value;
int** p2 = &p1;
```

**Схема памяти:**

```
┌──────────────┐
│   value      │
│  (значение)  │ 10
│  (адрес)     │ 0x100
└──────────────┘

┌──────────────┐
│    p1        │
│  (значение)  │ 0x100  ← адрес value
│  (адрес)     │ 0x200
└──────────────┘

┌──────────────┐
│    p2        │
│  (значение)  │ 0x200  ← адрес p1
│  (адрес)     │ 0x300
└──────────────┘
```

* `*p2` → значение по адресу `0x200`, то есть сам `p1`.
* `**p2` → значение по адресу `0x100`, то есть `value = 10`.

> Если ты делаешь `**p2 = 99;`, то реально меняется `value`.

##  Пример 3. Указатель на массив (через `fixed`)

```csharp
int[] arr = { 1, 2, 3 };
fixed (int* p = arr)
{
    *(p + 1) = 99;
}
```

**Схема памяти:**

```
arr → ┌──────────┬──────────┬──────────┐
      │ arr[0]=1 │ arr[1]=2 │ arr[2]=3 │
      └──────────┴──────────┴──────────┘
       0x100      0x104      0x108

p = 0x100
*(p + 1) = 99 → изменяет arr[1]
```

После выполнения:

```
arr = [1, 99, 3]
```


##  Пример 4. Указатель на структуру

```csharp
struct Point { public int X; public int Y; }
Point p = new Point { X = 5, Y = 10 };
Point* ptr = &p;
ptr->X = 20;
```

**Схема памяти:**

```
┌──────────────┐
│   Point p    │
│ X = 5 → 20   │
│ Y = 10       │
│ Адрес: 0x500 │
└──────────────┘

┌──────────────┐
│   ptr        │
│ Значение     │ 0x500
│ Адрес        │ 0x600
└──────────────┘
```

> `ptr->X` — это просто `(*ptr).X`.


##  Пример 5. Указатель на массив указателей

```csharp
int a = 1, b = 2, c = 3;
int*[] arr = { &a, &b, &c };
fixed (int** p = arr)
{
    **(p + 1) = 200;
}
```

**Схема:**

```
a = 1  (0x100)
b = 2  (0x104)
c = 3  (0x108)

arr → ┌────────┬────────┬────────┐
      │ 0x100  │ 0x104  │ 0x108  │   ← адреса a, b, c
      └────────┴────────┴────────┘
       0x200    0x208    0x210

p = 0x200
(p + 1) → 0x208 → содержит 0x104 → адрес переменной b
**(p + 1) = 200 → b = 200
```

Результат:

```
a = 1, b = 200, c = 3
```
