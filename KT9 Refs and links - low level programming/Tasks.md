##  **Кейс 1. Модификация массива через указатель**

### **Задача:**

Напиши программу, которая:

1. Создаёт массив `int[] numbers = { 1, 2, 3, 4, 5 }`.
2. С помощью указателя (`int* p`) проходит по элементам массива.
3. Увеличивает каждый элемент на 10.
4. Выводит массив **до** и **после** изменений.

### **Подсказка:**

* Используй `fixed (int* p = numbers)` — чтобы зафиксировать массив в памяти.
* Для доступа к элементам: `*(p + i)`.

### **Пример вывода:**

```
До: 1 2 3 4 5
После: 11 12 13 14 15
```

##  **Кейс 2. Работа с указателем на указатель**

### **Задача:**

Создай программу, которая:

1. Объявляет переменную `int x = 50;`
2. Создаёт указатель `int* p = &x;`
3. Создаёт указатель на указатель `int** pp = &p;`
4. Через `pp` изменяет значение `x` на `999`.
5. Выводит:

   * адрес переменной `x`,
   * адрес указателя `p`,
   * значение `x` до и после изменения через `pp`.

### **Подсказка:**

* Чтобы изменить `x` через двойной указатель: `**pp = 999;`
* Можно вывести адреса с помощью `(ulong)&x` или `(ulong)p`.

### **Пример вывода:**

```
Адрес x: 0x100
Адрес p: 0x200
Значение x до: 50
Значение x после изменения через **pp: 999
```
