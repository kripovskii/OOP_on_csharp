
## 1. Включаем поддержку unsafe-кода 

###  Вариант 1: через свойства проекта (предпочительный вариант)

1. Открой проект в **Visual Studio**.
2. Щёлкни правой кнопкой по проекту → **Properties (Свойства)**.
3. Перейди в раздел **Build (Сборка)**.
4. Поставь галочку **“Allow unsafe code” (Разрешить небезопасный код)**.
5. Сохрани изменения и пересобери проект.

---

###  Вариант 2: через `.csproj`

Открой файл проекта (`.csproj`) и добавь строку:

```xml
<PropertyGroup>
  <AllowUnsafeBlocks>true</AllowUnsafeBlocks>
</PropertyGroup>
```

---

##  2. Как объявлять и использовать указатели

Чтобы использовать указатели, нужно:

* объявить метод или блок с ключевым словом `unsafe`;
* использовать оператор `*` (разыменование);
* использовать оператор `&` (взятие адреса).

---

###  Пример 1: базовый пример

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int x = 10;
        int* p = &x;  // указатель на x

        Console.WriteLine($"Значение x: {x}");
        Console.WriteLine($"Адрес x: {(ulong)p:X}");
        Console.WriteLine($"Значение через указатель: {*p}");

        *p = 20;  // изменение значения через указатель

        Console.WriteLine($"Новое значение x: {x}");
    }
}
```

🧩 **Что происходит:**

* `int* p = &x;` — получаем адрес переменной `x`.
* `*p` — получаем значение по адресу.
* Можно изменять данные напрямую через `*p`.

---

### 🔹 Пример 2: использование указателей с массивами

```csharp
using System;

class Program
{
    unsafe static void Main()
    {
        int[] arr = { 1, 2, 3, 4, 5 };

        fixed (int* p = arr) // фиксируем массив в памяти
        {
            for (int i = 0; i < arr.Length; i++)
            {
                Console.WriteLine($"arr[{i}] = *(p + {i}) = {*(p + i)}");
            }
        }
    }
}
```

> `fixed` — нужен, чтобы **запретить сборщику мусора перемещать массив** во время работы с указателем.

---

###  Пример 3: структуры и указатели

```csharp
using System;

struct Point
{
    public int X;
    public int Y;
}

class Program
{
    unsafe static void Main()
    {
        Point p1;
        p1.X = 5;
        p1.Y = 10;

        Point* ptr = &p1;

        Console.WriteLine($"X: {ptr->X}, Y: {ptr->Y}");

        ptr->X = 20;
        ptr->Y = 40;

        Console.WriteLine($"Новые значения: X={p1.X}, Y={p1.Y}");
    }
}
```

 `->` — оператор доступа к полям через указатель (аналогично C/C++).



##  3. Когда это реально нужно

Используй `unsafe` **только если без него нельзя**. Например:

* для **работы с неуправляемыми API** (через `DllImport`);
* при **высокопроизводительных вычислениях**;
* для **манипуляций с байтами** и структурированной памятью;
* при **взаимодействии с C/C++ кодом**;
* в **игровых движках** (Unity ECS, например).

---

## ⚠️ 4. Важные замечания

* Указатели **нельзя использовать в управляемых типах** (например, внутри классов без `unsafe`).
* Они **не работают с объектами в куче**, кроме случаев, когда используется `fixed`.
* **Ошибки в указателях могут привести к сбоям программы** (нарушение доступа к памяти).
* В большинстве случаев лучше использовать:

  * `ref`, `out`, `in`
  * `Span<T>` и `Memory<T>` (более безопасные аналоги указателей в современном C#)

---

## 💡 5. Советы

* Всегда ограничивай область `unsafe` кода минимально возможной.
* Используй `fixed` при работе с массивами и строками.
* Не путай **управляемые ссылки** (`ref`) и **указатели** (`*`).
* Проверь, что **проект собирается с разрешением unsafe-кода** — иначе компилятор выдаст ошибку.
