# Передача параметров методов в C#

В языке C# параметры методов могут передаваться **по значению**, **по ссылке** или **как выходные параметры**. Понимание этих механизмов важно для эффективного и безопасного программирования.

## 1. Передача по значению (`by value`)

Это **стандартный способ** передачи параметров в C#. При этом **копия значения** передаётся в метод. Изменения внутри метода **не влияют** на оригинальную переменную.

```csharp
void Increment(int number)
{
    number++; // изменяется копия
}

int x = 5;
Increment(x);
Console.WriteLine(x); // Вывод: 5
```

> ⚠️ Для ссылочных типов (например, классов) копируется **ссылка**, а не сам объект. Это означает, что изменения **свойств объекта** будут видны снаружи, но **переприсвоение ссылки** — нет.

## 2. Передача по ссылке (`ref`)

Ключевое слово `ref` позволяет передавать параметр **по ссылке**, то есть метод работает **с оригинальной переменной**, а не с её копией.

Требования:
- Переменная **должна быть инициализирована** до передачи.
- И в объявлении метода, и при вызове нужно указать `ref`.

```csharp
void Increment(ref int number)
{
    number++;
}

int x = 5;
Increment(ref x);
Console.WriteLine(x); // Вывод: 6
```

## 3. Выходные параметры (`out`)

Ключевое слово `out` используется, когда метод **должен вернуть значение через параметр**. В отличие от `ref`:
- Переменная **не обязана быть инициализирована** до вызова.
- Метод **обязан присвоить значение** параметру `out` перед завершением.

```csharp
bool TryParseInt(string input, out int result)
{
    if (int.TryParse(input, out result))
    {
        return true;
    }
    result = 0; // обязательно присвоить
    return false;
}

string s = "123";
if (TryParseInt(s, out int number))
{
    Console.WriteLine(number); // Вывод: 123
}
```

> 💡 Начиная с C# 7.0, можно объявлять переменную прямо в вызове: `out int number`.

## 4. Переменное число аргументов (`params`)

Ключевое слово `params` позволяет передавать **переменное количество аргументов** одного типа.

- Должен быть **последним** параметром в списке.
- Может быть только **один** параметр с `params`.
- Передаётся как массив.

```csharp
void PrintNumbers(params int[] numbers)
{
    foreach (int n in numbers)
        Console.Write(n + " ");
}

PrintNumbers(1, 2, 3);        // Передаём три аргумента
PrintNumbers(new int[] {4, 5}); // Или массив
// Вывод: 1 2 3 4 5
```

## 5. Сравнение `ref`, `out` и передачи по значению

| Характеристика           | По значению | `ref`               | `out`               |
|--------------------------|-------------|---------------------|---------------------|
| Требуется инициализация  | Да          | **Да**              | **Нет**             |
| Метод может не менять    | Да          | Да                  | **Нет** (обязан)    |
| Передаётся оригинал      | Нет         | **Да**              | **Да**              |
| Используется для возврата| Нет         | Редко               | **Часто**           |

> 💡 Начиная с C# 7.2, появилась поддержка `in` — передача **только для чтения** по ссылке (для оптимизации производительности).

## 6. Примеры кода

### Полный пример

```csharp
using System;

class Program
{
    static void Main()
    {
        // По значению
        int a = 10;
        ModifyValue(a);
        Console.WriteLine($"После ModifyValue: {a}"); // 10

        // ref
        int b = 20;
        ModifyRef(ref b);
        Console.WriteLine($"После ModifyRef: {b}"); // 21

        // out
        if (GetRandomNumber(out int random))
        {
            Console.WriteLine($"Случайное число: {random}");
        }

        // params
        SumAndPrint(1, 2, 3, 4, 5);
    }

    static void ModifyValue(int x) => x = 999;

    static void ModifyRef(ref int x) => x++;

    static bool GetRandomNumber(out int number)
    {
        number = new Random().Next(1, 101);
        return true;
    }

    static void SumAndPrint(params int[] values)
    {
        int sum = 0;
        foreach (int v in values) sum += v;
        Console.WriteLine($"Сумма: {sum}");
    }
}
```

## Заключение

Понимание способов передачи параметров в C# помогает:
- Избегать неожиданных побочных эффектов.
- Писать более эффективный код (особенно с `ref` и `in` для больших структур).
- Использовать идиоматичные паттерны, такие как `TryParse` с `out`.

Выбирайте подходящий способ в зависимости от задачи:
- **По значению** — по умолчанию.
- **`ref`** — когда нужно изменить существующую переменную.
- **`out`** — когда метод возвращает дополнительное значение.
- **`params`** — для гибкости при вызове с разным числом аргументов.

---

> 📌 **Совет**: Для структур (`struct`) передача по значению может быть дорогой — в таких случаях рассмотрите использование `ref readonly` или `in` (C# 7.2+).
