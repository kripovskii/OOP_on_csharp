## Практическое задание

Реализуйте консольное приложение **«Система бронирования кинотеатра»**.

### Требования:
1. **Модель предметной области**
   - Создайте класс `Movie` (фильм) с полями: название, длительность.
   - Создайте класс `Seat` (место в зале) с номером и признаком занятости.

2. **Контейнер бизнес-правил**
   - В `Seat` запретите бронирование, если место уже занято.
   - Добавьте метод `Reserve()`, который отмечает место как забронированное.

3. **Логика приложения (сервис)**
   - Создайте класс `BookingService`, который:
     - позволяет выбрать фильм,
     - выбрать место,
     - оформить бронирование.

4. **Организация программы**
   - Создайте класс `CinemaHall`, который хранит список мест.
   - Добавьте методы для отображения свободных/занятых мест.

### Что должно быть в `Main()`:
- Создать несколько фильмов и зал с 10 местами.
- Вывести список фильмов.
- Дать пользователю выбрать фильм и место.
- Попробовать забронировать место.
- Показать итоговую схему зала.

### Дополнительно:
- Добавьте класс `Customer` (клиент), у которого хранится имя и список его бронирований.
- Реализуйте возможность отмены бронирования.
