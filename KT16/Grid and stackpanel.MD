# Компоновка в WPF — Grid и StackPanel

## 1. Введение в систему компоновки WPF

WPF использует мощную **layout-систему**, которая автоматически рассчитывает размеры и положение элементов. Любой контейнер компоновки:

* измеряет каждый дочерний элемент (Measure)
* располагает элементы (Arrange)
* перерасчитывает расположение при изменении окна, DPI, шрифта и т.д.

**Grid** и **StackPanel** — два самых используемых контейнера WPF.

---

# 2. Контейнер StackPanel

### 📌 Основная идея

StackPanel располагает элементы **в линию**, один за другим:

* сверху вниз (**Vertical**, значение по умолчанию)
* слева направо (**Horizontal**)

### 🔧 Главные свойства StackPanel

| Свойство                                    | Описание                                            |
| ------------------------------------------- | --------------------------------------------------- |
| `Orientation`                               | Направление компоновки: `Vertical` или `Horizontal` |
| `Margin`                                    | Внешние отступы                                     |
| `Padding`                                   | Внутренние отступы                                  |
| `HorizontalAlignment` / `VerticalAlignment` | Выравнивание StackPanel как элемента                |
| `Width` / `Height`                          | Фиксированные размеры (не всегда рекомендуется)     |

### ⭐ Особенности

* StackPanel **не ограничивает** дочерний элемент по мере измерения.
  Пример: при `Orientation="Vertical"` ширина определяется **широчайшим элементом**.
* Идеален для списков, колонок, панелей с кнопками.

### ▶ Пример: вертикальная панель

```xml
<StackPanel Orientation="Vertical" Margin="10">
    <Button Content="Кнопка 1" />
    <Button Content="Кнопка 2" />
    <Button Content="Кнопка 3" />
</StackPanel>
```

### ▶ Пример: горизонтальная панель

```xml
<StackPanel Orientation="Horizontal" Margin="10">
    <TextBlock Text="Имя:" Margin="0,0,10,0"/>
    <TextBox Width="150"/>
</StackPanel>
```

# 3. Контейнер Grid

### 📌 Основная идея

Grid — самый мощный контейнер компоновки, позволяющий разбивать интерфейс на:

* **строки**
* **столбцы**
* **области**, объединяя их

### 🔧 Типы размеров Grid

Каждая строка/столбец поддерживает три типа размеров:

| Тип                  | Пример                | Описание                        |
| -------------------- | --------------------- | ------------------------------- |
| Auto                 | `Height="Auto"`       | размер по содержимому           |
| Абсолютный           | `Height="50"`         | фиксированное значение          |
| Пропорциональный (*) | `Height="*"` или `2*` | деление свободного пространства |

Это делает Grid универсальным.

---

# 4. Определение строк и столбцов

### ▶ Пример: три строки

```xml
<Grid>
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto"/>
        <RowDefinition Height="*"/>
        <RowDefinition Height="Auto"/>
    </Grid.RowDefinitions>
</Grid>
```

### ▶ Пример: два столбца

```xml
<Grid.ColumnDefinitions>
    <ColumnDefinition Width="2*"/>
    <ColumnDefinition Width="*"/>
</Grid.ColumnDefinitions>
```

---

# 5. Размещение элементов в Grid

Используются свойства:

* `Grid.Row`
* `Grid.Column`
* `Grid.RowSpan`
* `Grid.ColumnSpan`

### ▶ Пример: размещение элементов

```xml
<Grid>
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto"/>
        <RowDefinition Height="*"/>
    </Grid.RowDefinitions>

    <Grid.ColumnDefinitions>
        <ColumnDefinition Width="*"/>
        <ColumnDefinition Width="2*"/>
    </Grid.ColumnDefinitions>

    <TextBlock Text="Меню" Grid.Row="0" Grid.Column="0"/>
    <TextBlock Text="Контент" Grid.Row="1" Grid.Column="1"/>
</Grid>
```

---

# 6. Grid vs StackPanel — когда какой использовать?

### ✔ StackPanel — когда подходит

* Нужно **простой линейный список элементов**
* Формы, списки кнопок, панели инструментов
* Нет необходимости в сложной адаптивной разметке

### ✔ Grid — когда использовать

* Нужен **полный контроль** над расположением
* Сложные формы ввода
* Адаптивные интерфейсы
* Разделение пространства пропорционально

---

# 7. Производительность

* **StackPanel работает быстрее**, т.к. имеет линейный алгоритм расположения.
* **Grid чуть медленнее**, так как требует двойного прохода компоновки (Measure и Arrange для таблицы).

Однако Grid незаменим в сложных интерфейсах.

---

# 8. Частые ошибки

### ❌ Ошибка: использовать StackPanel как адаптивный контейнер

StackPanel **не сжимает элементы**, они могут уехать за экран.

### ❌ Ошибка: использовать Grid без строк и столбцов

Если не задать строки/столбцы, Grid ведёт себя как обычный ContentControl — помещает 1 элемент.

### ❌ Ошибка: задавать фиксированные размеры там, где нужны `Auto` или `*`

# 9. Сравнительная таблица

| Характеристика           | StackPanel   | Grid                |
| ------------------------ | ------------ | ------------------- |
| Сложность                | Простая      | Сложная             |
| Управление расположением | Линейное     | Полное              |
| Адаптивность             | Низкая       | Высокая             |
| Использование в формах   | Ограниченное | Идеально подходит   |
| Производительность       | Быстрее      | Медленнее, но гибче |

---

# 10. Итог

Grid и StackPanel — фундамент WPF-компоновки:

* **StackPanel** — для простых вертикальных/горизонтальных списков
* **Grid** — для продвинутых интерфейсов, форм, таблиц, адаптивной верстки

Используйте StackPanel для скорости и простоты, Grid — для гибкости.
