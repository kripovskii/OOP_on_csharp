## Задание для должников по дедлайнам :)

### Конвертер величин (Unit Converter)

> ‼️ **При обноружении следов работы нейросети, задание будет аннулировано** ‼️

**Описание задачи:**  
Создайте простое desktop-приложение на WPF, которое позволяет конвертировать значения между разными единицами измерения. Для начала реализуйте конвертацию только в одной категории — например, **длина** (метры ↔ километры ↔ сантиметры ↔ миллиметры ↔ дюймы ↔ футы).

**Основные требования:**

1. **Интерфейс (XAML):**
   - Главное окно размером примерно 400x300.
   - Вверху: TextBlock с заголовком «Конвертер длин» (крупный шрифт).
   - Две основные секции (можно разместить в Grid с двумя строками или в StackPanel):
     - TextBox для ввода числового значения (только цифры и запятая/точка).
     - Два ComboBox:
       - Первый: «Из» — выбор исходной единицы.
       - Второй: «В» — выбор целевой единицы.
   - Button «Конвертировать».
   - Ниже: TextBlock для отображения результата (крупный шрифт, например: «1.00 метр = 100.00 сантиметров»).
   - Дополнительно: TextBlock с подсказкой или ошибкой (например, «Введите число»).

   Пример компоновки:
   ```
   [Заголовок]
   
   Введите значение: [_______________]
   
   Из: [ComboBox с единицами]    В: [ComboBox с единицами]
   
                [Конвертировать]
   
   Результат: [_____________________________]
   ```

2. **Функциональность (C#, code-behind):**
   - Заполните оба ComboBox одинаковым списком единиц (можно в XAML или в конструкторе окна).
   - По нажатию на кнопку:
     - Считайте значение из TextBox.
     - Проверьте, что это валидное число (double). Если нет — покажите сообщение об ошибке.
     - Переведите значение сначала в базовую единицу (например, метры).
     - Затем из метров переведите в целевую единицу.
     - Выведите результат с двумя знаками после запятой.
   - Сделайте конвертацию в обе стороны (например, метры → дюймы и дюймы → метры работают одинаково).

   - Добавьте ещё одну категорию (например, температура: Цельсий ↔ Фаренгейт ↔ Кельвин) и RadioButton'ы для выбора категории.
- Сделайте конвертацию автоматической при изменении значения или выбора единиц (используйте событие TextChanged или SelectionChanged).

3. **Коэффициенты перевода (пример для длины, в метрах):**
   - Миллиметр: 0.001
   - Сантиметр: 0.01
   - Метр: 1
   - Километр: 1000
   - Дюйм: 0.0254
   - Фут: 0.3048
> Другие коэффициенты искать в интернете
