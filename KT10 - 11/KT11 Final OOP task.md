**Задание: Знание основ объектно-ориентированного программирования (ООП) на C#**

---

### Цель задания:
Проверить понимание ключевых принципов ООП (инкапсуляция, наследование, полиморфизм, абстракция) и умение применять их при разработке на языке C#.

---

### Условие:

Разработайте консольное приложение на C#, моделирующее систему управления транспортными средствами.

#### Требования:

1. **Создайте базовый абстрактный класс `Vehicle`**, содержащий:
   - Защищённые поля: `brand` (марка), `model` (модель), `year` (год выпуска).
   - Конструктор для инициализации этих полей.
   - Абстрактный метод `StartEngine()`, который должен быть реализован в дочерних классах.
   - Виртуальный метод `GetInfo()`, возвращающий строку с общей информацией о транспортном средстве.
   - Свойства с геттерами (и сеттерами при необходимости) для всех полей.

2. **Создайте два производных класса:**
   - `Car` — легковой автомобиль. Добавьте поле `numberOfDoors` (количество дверей).
   - `Motorcycle` — мотоцикл. Добавьте поле `hasSidecar` (наличие коляски: `bool`).

   В каждом из этих классов:
   - Реализуйте конструктор, вызывающий базовый конструктор.
   - Переопределите метод `StartEngine()` так, чтобы он выводил соответствующее сообщение (например, `"Двигатель автомобиля заведён"`).
   - Переопределите метод `GetInfo()`, добавив специфичную информацию (например, количество дверей или наличие коляски).

3. **Продемонстрируйте полиморфизм:**
   - Создайте несколько объектов типа `Car` и `Motorcycle`.
   - Вызовите для каждого объекта методы `StartEngine()` и `GetInfo()`.

4. **Инкапсуляция:**
   - Убедитесь, что внутренние поля классов недоступны напрямую извне.
   - Используйте свойства (`public` геттеры и, при необходимости, сеттеры) для доступа к данным.

5. **(Дополнительно, для продвинутых):**
   - Создайте интерфейс `IDrivable` с методом `Drive()`.
   - Реализуйте этот интерфейс в обоих классах (`Car`, `Motorcycle`).
   - Продемонстрируйте использование интерфейса в основной программе.

---

### Ожидаемый результат:
Консольное приложение, которое:
- Корректно создаёт объекты различных типов транспортных средств.
- Использует наследование и полиморфизм.
- Соблюдает принципы инкапсуляции.
- Выводит информацию о каждом транспортном средстве и запускает его двигатель.
