#  Конструктор класса в C

## 1. Определение конструктора

Конструктор --- это специальный метод класса в C#, который вызывается
автоматически при создании объекта.\
Его основная задача --- инициализация объекта, то есть задание начальных
значений полей или выполнение необходимых действий при создании
экземпляра.

## 2. Синтаксис конструктора

Конструктор имеет то же имя, что и класс, и не имеет возвращаемого типа
(даже `void`).

``` csharp
class Person
{
    public string Name;
    public int Age;

    // Конструктор
    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }
}
```

## 3. Виды конструкторов

### 3.1. Конструктор по умолчанию

Если в классе не определено ни одного конструктора, компилятор создаёт
**конструктор по умолчанию** (без параметров).\
Если хотя бы один конструктор определён явно, конструктор по умолчанию
автоматически **не создаётся**.

``` csharp
class Car
{
    public string Model;

    // Конструктор по умолчанию
    public Car()
    {
        Model = "Неизвестно";
    }
}
```

### 3.2. Конструктор с параметрами

Позволяет передавать данные при создании объекта.

``` csharp
Car car = new Car("Toyota");
```

### 3.3. Статический конструктор

Используется для инициализации **статических членов** класса.\
Выполняется один раз при первом обращении к классу.

``` csharp
class Config
{
    public static string Version;

    // Статический конструктор
    static Config()
    {
        Version = "1.0.0";
    }
}
```

### 3.4. Конструктор копирования

В C# нет встроенного конструктора копирования, но его можно реализовать
вручную.

``` csharp
class Person
{
    public string Name;
    public int Age;

    // Конструктор копирования
    public Person(Person other)
    {
        Name = other.Name;
        Age = other.Age;
    }
}
```

## 4. Перегрузка конструкторов

В одном классе может быть несколько конструкторов, отличающихся списком
параметров. Это называется **перегрузкой**.

``` csharp
class Book
{
    public string Title;
    public int Pages;

    // Конструктор без параметров
    public Book()
    {
        Title = "Без названия";
        Pages = 0;
    }

    // Конструктор с параметрами
    public Book(string title, int pages)
    {
        Title = title;
        Pages = pages;
    }
}
```

## 5. Вызов одного конструктора из другого (`this`)

Можно вызывать один конструктор из другого с помощью ключевого слова
`this`.

``` csharp
class Student
{
    public string Name;
    public int Age;

    public Student() : this("Неизвестно", 18) { }

    public Student(string name, int age)
    {
        Name = name;
        Age = age;
    }
}
```

## 6. Отличие конструктора от метода

-   Конструктор **не имеет возвращаемого типа**.
-   Имя конструктора совпадает с именем класса.
-   Вызывается **автоматически** при создании объекта.
