# Базовые конструкторы
**Цель: Научиться создавать и использовать разные типы конструкторов.**
---
1. Создайте класс Book со следующими свойствами:

- `Title` (string) - название книги

- `Author` (string) - автор

- `Year` (int) - год издания

2. Задачи:

- Реализуйте конструктор по умолчанию, который инициализирует свойства значениями по умолчанию.

- Реализуйте параметрический конструктор, который принимает все три параметра.

- Реализуйте конструктор, который принимает только название и автора, а год устанавливает в 2024.

- Создайте метод `DisplayInfo()`, который выводит информацию о книге.

- В методе `Main` создайте несколько объектов книги, используя разные конструкторы.
