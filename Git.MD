# Инструкция по работе с Git в Visual Studio 2022

## 1. Открытие и настройка Git
1. Запустите **Visual Studio 2022**.
2. Перейдите в меню **View → Git Repository** или используйте вкладку **Git** внизу IDE.
3. Убедитесь, что Git установлен на вашем компьютере. Если нет — [скачайте Git](https://git-scm.com/downloads) и установите его.
4. Настройте имя и email для коммитов:
   - **Git → Settings → Git Global Settings**
   - Укажите:
     ```bash
     git config --global user.name "Ваше имя"
     git config --global user.email "you@example.com"
     ```

## 2. Создание нового репозитория
1. В меню **Git → Create Git Repository…**.
2. Выберите папку с проектом.
3. Укажите путь для локального репозитория.
4. (Опционально) Подключите удалённый репозиторий, например на GitHub или GitLab.

## 3. Клонирование существующего репозитория
1. В меню **Git → Clone Repository…**.
2. Вставьте URL удалённого репозитория (например, с GitHub).
3. Укажите папку для клонирования.
4. Нажмите **Clone**.

## 4. Основные операции

### Проверка статуса
- В **Git Changes** отображаются все изменённые файлы.

### Добавление файлов в индекс
1. Откройте окно **Git Changes**.
2. Выберите файлы и нажмите **+ (Stage)**.

### Коммит изменений
1. В окне **Git Changes** введите сообщение коммита.
2. Нажмите **Commit All** или **Commit All and Push**.

### Push (отправка на сервер)
- **Git → Push** или кнопка **Push** в окне **Git Changes**.

### Pull (получение изменений)
- **Git → Pull** для обновления локального кода.

### Fetch (проверка обновлений)
- **Git → Fetch** для проверки новых изменений без их применения.

## 5. Работа с ветками
1. Откройте окно **Git Repository**.
2. Справа отображается список веток.
3. Для создания новой ветки:
   - **New Branch…**
   - Укажите имя ветки.
   - Нажмите **Create Branch**.
4. Для переключения веток — выберите нужную и нажмите **Checkout**.

## 6. Слияние веток (Merge)
1. Перейдите в ветку, куда хотите объединить изменения.
2. **Right-click на ветку → Merge into Current Branch**.
3. Разрешите конфликты (если есть) с помощью встроенного редактора.

## 7. Разрешение конфликтов
1. При конфликте откройте файл — Visual Studio подсветит различия.
2. Используйте опции:
   - **Accept Current Change**
   - **Accept Incoming Change**
   - **Accept Both Changes**
3. После разрешения сохраните файл и сделайте коммит.

## 8. Работа с удалёнными репозиториями
- Добавить новый origin:
  ```bash
  git remote add origin https://github.com/user/repo.git


* В Visual Studio: **Git → Manage Remotes…**

## 9. Просмотр истории

1. Откройте окно **Git Repository**.
2. Перейдите на вкладку **History** для просмотра коммитов.

---

## Полезные сочетания

* **View → Git Changes** — список изменений.
* **View → Git Repository** — работа с ветками и историей.
* **Alt + \`** — открыть **Team Explorer / Git меню**.
